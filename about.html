소개

— 비즈니스 스토리 + 팀 · 차별화 포인트

“PBN, 너무 비싸고 복잡했어요. 그래서 우리가 만들었죠. 서버리스로 10분이면 끝나는 툴. 코드 한 줄 몰라도 됩니다.”

안녕하세요, 저는 PBN 자동 생성 배포 툴을 만든 사람입니다. 3년 전, 겨울에 난방도 안 되는 창고에서 맥북 하나로 시작했어요. 처음엔 그냥 내 SEO 프로젝트를 위해 만든 스크립트였는데, 주변에서 '이거 팔아요?' 라고 묻기 시작하면서 지금의 툴이 탄생했습니다.

🏗️ 비즈니스 스토리

2019 — 창고의 반짝임

프리랜서 SEO로 일하면서 매번 PBN 도메인을 사고, 호스팅 연결하고, 컨텐츠 올리고… 너무 지루했어요. 특히 여러 사이트를 한 번에 배포할 방법이 없어서 답답했죠. 어느 새벽, 맥주를 마시다가 '서버리스 함수로 도메인 파밍하고, 깃헙 액션으로 배포하면 되지 않을까?' 라는 아이디어가 떠올랐습니다. 그게 전부예요.

2021 — 첫 유료 사용자

처음엔 그냥 CLI 툴이었는데, 지인이 "나도 쓰게 해줘" 하면서 5명이 모였습니다. 한 달 후엔 30명. 놀랍게도 코드를 모르는 마케터분들이 "이거 대박인데, 웹 인터페이스 만들어줘" 라고 요청하셨어요. 그래서 만든 게 지금의 PBN 자동 생성 배포 툴입니다. 서버리스, 10분, 클릭 몇 번이면 PBN 완성.

🔧 차별화 포인트 — 왜 우리 툴일까?

⚡ 10분 PBN

도메인 등록부터 컨텐츠 배포, 링크 연결까지. 진짜 10분이면 끝납니다. 타이머 재봤어요. 커피 한 잔 내리는 시간이 더 길어요.

☁️ 서버리스 · 유지비 0

AWS Lambda + S3 + CloudFront로 작동합니다. 트래픽 없으면 비용 0원. PBN 유지비로 스트레스 받지 마세요.

🖱️ 코드 없음

마우스 클릭과 간단한 설정만으로 PBN 사이트가 생성됩니다. HTML 몰라도, 서버 몰라도 괜찮아요. 저희 할머니도 쓰실 수 있는 UI.

🔗 티어드 링크 자동

PBN 사이트들끼리 티어드 링크 구조를 자동으로 설정합니다. SEO 파워 극대화. 수동으로 하면 3일 걸릴 작업이 3초.
